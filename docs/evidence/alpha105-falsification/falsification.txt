(1) MUTATION 6 SURVIVED THE FIRST PASS, and it was a hole in MY OWN tests.
    «a page that came up short is reported as the whole page» removes

        if (count($rows) !== $expected) { return null; }

    from `DbProductRepository::reconciliationPage()`. Every test in
    `CatalogueReconciliationTest` read a HEALTHY database, where the count and
    the list always agree — so the guard was unreachable, and an unreachable
    guard is byte for byte indistinguishable from an absent one (`alpha.80`).

    Closed with a behavioural test that injects the refusal into the LIST
    statement by name and leaves the `COUNT(*)` beside it working, plus the
    control that the same call answers the whole page once the refusal stops:

        CatalogueReconciliationTest::testAPageWhoseRowsCouldNotBeReadIsNullRatherThanEmpty
