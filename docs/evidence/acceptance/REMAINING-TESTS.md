# آزمون‌های باقی‌مانده برای محیطی مشابه سایت تک‌طب

این فهرست فقط چیزهایی را می‌آورد که **اجرا نشده‌اند**. هر سطر پیش‌شرط، دستور
اجرا و مدرک لازم دارد. هیچ‌کدام روی `tecteb.com` یا `staging.tecteb.com` اجرا
نشده و در مجوز فعلی هم نیست؛ همه باید روی یک **WordPress یکبارمصرف با داده
مصنوعی که محیط سایت را بازسازی می‌کند** اجرا شوند.

## قاعده‌ای که تغییر نمی‌کند

هیچ سطری بدون **مدرک قابل بازتولید** به `Passed` تبدیل نمی‌شود، و «اجرا شد و
خطا ندیدم» مدرک نیست. برای هر گیت: فایل خروجی، نسخه‌های محیط، و exit code
واقعی همان دستور (نه `tee`).
