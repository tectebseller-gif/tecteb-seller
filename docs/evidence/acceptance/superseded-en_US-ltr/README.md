# اجرای پیشین دسترس‌پذیری — جایگزین شده

این پوشه فقط برای **تاریخچه** است. اجرای اول بررسی‌های wp-admin سه نقص روشی
داشت که در بازبینی مالک مشخص شد:

1. موردی به نام `zoom200` ثبت شده بود که در واقع `viewport=640×512` با
   `deviceScaleFactor=2` بود — **شبیه‌سازی فضای چیدمان**، نه زوم مرورگر.
2. اولین توقف کیبورد با `focus()` و افزودن `tabindex` اثبات شده بود، نه با
   پیمایش واقعی Tab؛ و شرط لینک پرش فقط hash را می‌سنجید، نه رسیدن فوکوس.
   «رسیدن به کنترل‌ها» هم فقط وجود یک توقف داخل افزونه را می‌سنجید.
3. wp-admin انگلیسی و LTR بود؛ فقط locale مرورگر روی `fa-IR` تنظیم شده بود،
   که زبان یا جهت خود وردپرس را عوض نمی‌کند.

اجرای اصلاح‌شده در `../wpadmin-a11y/` و `../wpadmin-a11y-with-wc/` است.
تصاویر این اجرا نگه داشته نشده‌اند؛ فقط JSON و log برای مقایسه مانده‌اند.

| فایل | چیست |
|---|---|
| `no-wc-wpadmin-a11y.json` / `.log` | اجرای پیشین، WooCommerce غیرفعال (۱۸۸ بررسی) |
| `with-wc-wpadmin-a11y.json` / `.log` | اجرای پیشین، WooCommerce فعال (۱۸۸ بررسی) |

نتیجه آن اجرا هم ۰ شکست بود؛ آنچه عوض شده **روش و نام‌گذاری** است، نه یافته‌ها.
