# دسترس‌پذیری و چیدمان روی wp-admin واقعی — fa_IR و RTL

اجرای `tools/browser/check-wpadmin.mjs` روی همان WordPress یکبارمصرف پذیرش،
با نشست واقعی مدیرکل و **زبان مدیریت وردپرس روی fa_IR با جهت راست‌به‌چپ**.

| پوشه | WooCommerce | نتیجه |
|---|---|---|
| `wpadmin-a11y/` (همین‌جا) | **غیرفعال** | ۲۵۲ بررسی، ۰ شکست |
| `../wpadmin-a11y-with-wc/` | **فعال (11.0.1)** | ۲۵۲ بررسی، ۰ شکست |
| `../superseded-en_US-ltr/` | — | اجرای پیشین با wp-admin انگلیسی/LTR و نام‌گذاری قدیمی زوم؛ **جایگزین شده**، برای تاریخچه نگه داشته شده |

## ۱. زبان و جهت — از خود سند، نه از locale مرورگر

locale مرورگر wp-admin را فارسی یا RTL نمی‌کند. وردپرس جهت را از ترجمه رشته
`ltr` در بافت `text direction` می‌گیرد، و آن فقط از یک فایل `.mo` واقعی می‌آید.

بررسی `wp-admin-is-fa-IR-rtl` در **هر ۲۸ بارگذاری صفحه** این‌ها را از سند
سرو‌شده می‌خواند و همه باید درست باشند:

```
html lang="fa-IR"  dir="rtl"  body.rtl=true  computedDirection=rtl
adminRtlStylesheets=1   (با WooCommerce فعال: 2)
```

`locale.samples` در `wpadmin-a11y.json` نمونه‌های خام همین مقادیر است.

### بسته زبان — دقیقاً چه چیزی نصب شد

`translate.wordpress.org`، `downloads.wordpress.org` و `api.wordpress.org` هر
سه از این کانتینر مسدودند (403)، پس بسته رسمی فارسی قابل دریافت نبود. به‌جای
آن `tools/wp-lang/make-fa-ir-mo.py` یک بسته **حداقلی** می‌سازد که:

- ورودی `text direction` → `rtl` را دارد (همان چیزی که `is_rtl()` را true می‌کند)،
- به‌علاوه حدود بیست رشته پوسته مدیریت (پیشخوان، افزونه‌ها، کاربران، …).

این **ترجمه رسمی فارسی وردپرس نیست** و هر رشته‌ای که در آن نباشد انگلیسی
می‌ماند. آنچه این بسته تضمین می‌کند دقیقاً همان شرط تحت آزمون است: locale
واقعی `fa_IR`، `is_rtl()` درست، و بارگذاری شیوه‌نامه‌های `*-rtl.css` مدیریت.
در تصاویر، نوار مدیریت وردپرس به سمت راست منتقل شده است — این کار خودِ
وردپرس است، نه CSS افزونه.

## ۲. زوم — دو چیز متفاوت، با دو نام متفاوت

| نام | چیست | نتیجه |
|---|---|---|
| `layout-space-640x512` | **شبیه‌سازی فضای چیدمان**: emulation سطح CDP که فضای چیدمانِ یک صفحه ۱۲۸۰×۱۰۲۴ در ۲۰۰٪ را به صفحه می‌دهد. زوم نیست | ۴ صفحه، بدون اسکرول افقی |
| `zoom200-browser` | **زوم واقعی در سطح مرورگر**: یک Chromium جدا با `--force-device-scale-factor=2` و پنجره ۶۴۰×۵۱۲ DIP — یعنی پنجره فیزیکی واقعی ۱۲۸۰×۱۰۲۴ که هر پیکسل CSS آن دو پیکسل دستگاه را می‌پوشاند. context با `viewport: null` ساخته می‌شود، پس Playwright **هیچ** `Emulation.setDeviceMetricsOverride` نمی‌فرستد | ۴ صفحه، بدون اسکرول افقی |
| زوم Ctrl+ خود مرورگر (HostZoomMap) | از Playwright/CDP قابل تنظیم نیست | **`Not Run`** |

بررسی `browser-really-scaled` پیش از هر سنجش، خودِ مقیاس را اثبات می‌کند:

```
devicePixelRatio=2  innerWidth=640  outerWidth=640  screen=400x300
narrowMediaQuery=true  rootZoom=1  (no CDP viewport override)
```

`rootZoom=1` مهم است: نتیجه از `zoom` در CSS نیامده. `narrowMediaQuery=true`
یعنی media queryها هم مثل زوم واقعی پاسخ داده‌اند — چیزی که `zoom` در CSS
انجام **نمی‌دهد** و به همین دلیل استفاده نشد.

## ۳. کیبورد — با Tab واقعی، بدون focus() و بدون دست‌کاری tabindex

پیمایش از بالای سند شروع می‌شود و فقط کلید Tab فشرده می‌شود. تنها تماس با DOM
یک نشانه `data-tmc-probe` برای شناسایی عناصر است که نه ترتیب focus را عوض
می‌کند نه ظاهر را.

| بررسی | چه چیزی را الزام می‌کند |
|---|---|
| `skip-link-is-the-first-plugin-stop` | پس از عبور از **۵۸ توقف پوسته وردپرس**، اولین توقف داخل `.tmc-admin` باید لینک پرش باشد |
| `every-plugin-control-is-reachable` | فهرست کنترل‌های focusable از خود صفحه استخراج می‌شود و Tab باید به **همه** آن‌ها برسد (پیشخوان ۱۰/۱۰، سلامت ۶/۶، تنظیمات ۱۰/۱۰، ماژول‌ها ۶/۶) |
| `skip-link-reachable-by-tab` | خود لینک پرش با Tab قابل رسیدن است |
| `skip-link-reaches-main` | پس از Enter، هم `location.hash === '#tmc-main'` **و هم** فوکوس واقعاً روی مقصد باشد: `activeElement=<main id="tmc-main">` |
| `focus-visible` | هر توقف داخل افزونه حلقه focus دارد |

و نوار مدیریت وردپرس (در سمت راست، چون RTL است) در آن‌ها دیده می‌شود.

## ۵. آنچه این اجرا ثابت نمی‌کند

بررسی خودکار جای **screen reader دستی** را نمی‌گیرد؛ آن سطر `Not Run` است.
زوم Ctrl+ خود مرورگر هم `Not Run` است (بالا). اجرا فقط روی Chromium 141 بود.
بسته زبان حداقلی است و ترجمه رسمی فارسی نیست. قالب فعال سایت مالک و
افزونه‌های آن حاضر نبودند.
