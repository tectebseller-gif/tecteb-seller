آینهٔ محیط نمایشی — بازارگاه تک‌طب 0.1.0-alpha.24

صفحه‌های واقعیِ محیط نمایشی، از چشم هر چهار نقش. HTML و CSS و فونت و تصویرها همان‌هایی هستند که سایت می‌فرستد.

این آینه چه هست و چه نیست

  • هست: ظاهر واقعی هر صفحه، با چیدمان و راست‌به‌چپ و فونت واقعی. پنجرهٔ مرورگر را باریک کنید تا حالت موبایل را ببینید — همان CSS است.
  • نیست: زنده. فرم‌ها ثبت نمی‌شوند، دکمه‌ها چیزی را تغییر نمی‌دهند و جاوااسکریپت عمداً حذف شده است.
  • برای «وارد شوم و کار کنم» یک میزبان واقعی لازم است؛ نیاز دقیق دسترسی در docs/demo-hosting-request-fa.md نوشته شده.

مدیر بازارگاه

همان صفحه‌هایی که با tmcowner دیده می‌شوند.

  1. پیشخوان بازارگاه /wp-admin/admin.php?page=tmc-dashboard
  2. بررسی فروشندگان /wp-admin/admin.php?page=tmc-vendor-applications
  3. بررسی محصول /wp-admin/admin.php?page=tmc-product-review
  4. وضعیت فروش بازارگاه /wp-admin/admin.php?page=tmc-storefront
  5. تسویه و برداشت /wp-admin/admin.php?page=tmc-withdrawals
  6. گزارش‌ها /wp-admin/admin.php?page=tmc-reports
  7. ممیزی /wp-admin/admin.php?page=tmc-audit
  8. تنظیمات /wp-admin/admin.php?page=tmc-settings
  9. سفارش‌های ووکامرس /wp-admin/admin.php?page=wc-orders

فروشنده

پیشخوان فروشگاهِ تأییدشده — کارِ امروز اول، بعد بقیه.

  1. پیشخوان فروشنده /vendor/
  2. محصولات /vendor/products/
  3. افزودن محصول /vendor/products/?product=new
  4. سفارش‌ها و ارسال /vendor/orders/
  5. تنظیمات فروشگاه /vendor/store/
  6. پرسنل /vendor/staff/
  7. امور مالی /vendor/finance/
  8. گزارش‌های فروشنده /vendor/reports/
  9. پشتیبانی و تیکت /vendor/support/

پرسنل فروشگاه

همان فروشگاه، با مرزِ دسترسی: «تنظیمات فروشگاه» باید رد شود.

  1. پیشخوان پرسنل /vendor/
  2. محصولات — دید پرسنل /vendor/products/
  3. سفارش‌ها — دید پرسنل /vendor/orders/
  4. تنظیمات فروشگاه — باید رد شود /vendor/store/

خریدار

سطح عمومی: فروشگاه، صفحهٔ فروشنده، سبد و حساب کاربری.

  1. فروشگاه /?post_type=product
  2. صفحهٔ عمومی فروشگاه /?tmc_store=2
  3. صفحهٔ محصول (صفحهٔ محصول)
  4. سبد خرید /cart/
  5. حساب کاربری /my-account/
  6. سفارش‌های من /my-account/orders/
