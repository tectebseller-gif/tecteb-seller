# پویش موارد حیاتی انتشار (§۸)

**نسخهٔ هدف:** `0.1.0-alpha.103` · **ساختار داده:** ۳۹، بدون migration

§۸ دستور یک فهرست بلند است که «نباید جا بیفتد». این سند هر بند را با **یک
وضعیت واقعی** می‌آورد — ✅ بسته، ⚠️ بسته روی کد و اثبات‌نشده روی تولید، یا
❌ `Not Run`/باز — و جایی که وضعیت ✅ است، می‌گوید **چه چیزی** آن را نگه
می‌دارد: یک آزمون، یک کلید یکتا، یا نبودِ یک قابلیت.

⛔ **و هیچ بندی با «احتمالاً درست است» بسته نمی‌شود.** هر ردیفِ ✅ یک فایل یا
یک اندازه‌گیری را نام می‌برد.
