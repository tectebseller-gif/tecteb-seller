# نسخه Markdown تولیدشده از اسناد مرجع

این پوشه نسخه Markdown دو سند DOCX مرجع را نگه می‌دارد. این فایل‌ها **مرجع
نیستند**؛ مرجع همان DOCX در `docs/` است و در تعارض، DOCX مقدم است.

- محتوا ماشینی تولید شده (`tools/docx-to-markdown.py`). هیچ جمله‌ای اضافه
  و هیچ تفسیری جایگزین متن مرجع نشده است.
- روش تطبیق، نتایج عددی و **فهرست صریح اختلاف‌های باقی‌مانده** (قالب‌بندی،
  سرفصل‌های استنباطی UX، فهرست‌ها، سرصفحه/پاصفحه، callout، ترتیب ستون):
  **[`EXTRACTION-FIDELITY.md`](EXTRACTION-FIDELITY.md)**.
- بازتولید و تطبیق: `python3 tools/verify-extraction.py` (exit 0 = یکسان).

اگر نیاز به توضیح یا یادداشت دارید، در فایل جدا بنویسید، نه داخل این دو
فایل.
