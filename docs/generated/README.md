# نسخه Markdown تولیدشده از اسناد مرجع

این پوشه نسخه Markdown **وفادار** دو سند DOCX مرجع را نگه می‌دارد. این فایل‌ها
مرجع نیستند؛ مرجع همان DOCX در `docs/` است. در تعارض، DOCX مقدم است.

## روش تولید

```bash
python3 tools/docx-to-markdown.py docs/Tecteb-Marketplace-Core-Master-Spec-v0.3.docx \
  > docs/generated/Tecteb-Marketplace-Core-Master-Spec-v0.3.md
python3 tools/docx-to-markdown.py docs/Tecteb-Marketplace-Core-UX-Wireframe-Spec-v0.2.docx \
  > docs/generated/Tecteb-Marketplace-Core-UX-Wireframe-Spec-v0.2.md
```

استخراج‌کننده تمام گره‌های `w:p` و `w:tbl` بدنه سند را پیمایش می‌کند و
پاراگراف، سرفصل، فهرست و **جدول‌ها** را نگه می‌دارد. `w:tab`، `w:br` و
`w:hyperlink` نیز پوشش داده شده‌اند.

## تطبیق فیدلیتی (اجراشده در ۶ سپتامبر ۲۰۲۶)

مقایسه بین مجموع کاراکترهای گره‌های `w:t` سند اصلی و متن استخراج‌شده، پس از
حذف کاراکترهای داربست Markdown (`#`, `|`, `-`, فاصله و خط جدید):

| سند | کاراکتر `w:t` خام | کاراکتر نرمال‌شده مرجع | کاراکتر نرمال‌شده استخراج | پوشش |
|---|---|---|---|---|
| Master Spec v0.3 | ۳۲٬۶۱۴ | ۲۷٬۴۶۹ | ۲۷٬۴۶۹ | ۱۰۰٫۰٪ |
| UX Spec v0.2 | ۱۶٬۸۵۷ | ۱۴٬۳۱۳ | ۱۴٬۳۹۰ | ۱۰۰٫۵٪ |

اختلاف ۰٫۵٪ در سند UX از جداکننده `<br>` بین چند پاراگراف داخل یک سلول جدول
می‌آید؛ متن حذف‌شده‌ای وجود ندارد. هیچ‌کدام از دو سند `w:txbxContent`
(کادر متنی/شکل) ندارند، بنابراین متنی خارج از این پیمایش باقی نمانده است.

## هشدار

محتوای این پوشه ماشینی تولید شده است. هیچ جمله‌ای به آن اضافه نشده و هیچ
تفسیری جای متن مرجع را نگرفته است. اگر نیاز به افزودن توضیح داشتید، آن را در
یک فایل جدا بنویسید، نه داخل این دو فایل.
