هسته بازارگاه تک‌طب: زیرساخت و چهار صفحه مدیریت. نسخه آزمایشی.

== Description ==

این نسخه فقط زیرساخت فاز اول را دارد: چرخه نصب/ارتقا، بارگذار ماژول،
پیکربندی، لاگ ممیزی، تشخیص محیط و چهار صفحه فارسی مدیریت (پیشخوان، سلامت،
تنظیمات، ماژول‌ها) به‌همراه یک endpoint خصوصی سلامت.

قابلیت‌های فروشنده، محصول، سفارش، کمیسیون، تسویه و مهاجرت ساخته نشده‌اند.
هیچ ایمیل، پیامک یا پرداختی از خود افزونه ارسال نمی‌شود؛ این قفل در نسخه
آزمایشی قابل باز کردن نیست.

== Compatibility ==

عدد «Requires at least: 6.3» یک **حداقل پیشنهادی و آزموده‌نشده** است، نه نتیجه
آزمون. هیچ نسخه‌ای از WordPress یا WooCommerce با این افزونه اجرا نشده است.
وضعیت سطربه‌سطر در docs/compatibility-matrix.md و پروتکل آزمون در
docs/installation.md بند ۴ آمده است.
