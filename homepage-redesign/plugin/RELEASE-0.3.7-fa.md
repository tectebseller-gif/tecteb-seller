## تغییر
وقتی این افزونه صفحهٔ نخست را جایگزین می‌کند، Elementor تا 0.3.6 همچنان CSS ِ همان برگه (`post-<ID>.css` یا CSS ِ
درون‌خطی)، فونت‌ها و آیکون‌هایش و «دارایی‌های صفحه» ِ ابزارک‌هایش را بارگذاری می‌کرد (روی بستر: `swiper`، `e-swiper`،
`widget-image-carousel`، `widget-testimonial`، `widget-counter`، `e-animation-grow` و JS ِ `swiper` و
`jquery-numerator`) — چون این تصمیم را Elementor از روی پست جاری می‌گیرد و فیلتری ندارد. هیچ‌کدام روی صفحه نبود.

0.3.7 پست جاری را فقط در فاصلهٔ دو قلاب خودِ Elementor — `elementor/frontend/after_enqueue_styles` تا
`elementor/frontend/after_enqueue_post_styles` — کنار می‌گذارد و بلافاصله برمی‌گرداند، فقط وقتی صفحهٔ نخست واقعاً
جایگزین می‌شود (نه در ویرایشگر، پیش‌نمایش، `?tecteb_home_original=1` یا وقتی «صفحهٔ نخست» خاموش است). هدر، فوتر، Popup و
Kit ِ Elementor جدا بارگذاری می‌شوند و دست نمی‌خورند.
