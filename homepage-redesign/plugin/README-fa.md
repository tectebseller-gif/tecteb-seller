**سخت‌سازی در برابر قالب و Elementor** (`src/hardening.css`): reset ِ Hello Elementor

بی سخت‌سازی: ۶ و ۱۳ نشت — `readiness/`.) سه تفاوتِ عمدی با پیش‌نمایش: padding ِ

### آنچه اجرا **نشد** (`Not Run`، نه «قبول»)
- **Elementor واقعی** (wordpress.org و انتشارهای GitHub از این محیط مسدودند): سازگاری با
  یک kit ِ نمونه سنجیده شد، نه با Elementor.
- **PHP 8.1 واقعی**: مفسر در این محیط نیست؛ PHPCompatibility با `testVersion 8.1-` ۰ خطا.
- **LiteSpeed Cache، Rank Math، دکان، Persian Woo، JetWooBuilder**: نصب‌شدنی نیستند.
  یعنی: پاک‌سازی واقعی کش، اینکه lazyload ِ LiteSpeed `data-no-lazy`/`skip-lazy` را
  روی تصویر Hero رعایت می‌کند، ارقام فارسی قیمت (Persian Woo)، و رفتار در کنار دکان.
- **کاتالوگ واقعی** (۱٬۰۷۰ دسته، ۱۸۴ محصول) و **هر چیزی روی staging یا سایت اصلی**.
- قالب Hello از سورس ساخته شد و سه فایل JS ِ فقط‌مدیریتی‌اش جای‌خالی محلی دارند؛ این
  فقط روی پیشخوان محلی اثر داشت و به صفحهٔ اصلی ربطی ندارد.

## ۴. راهنمای نصب (فقط پس از تأیید شما؛ اول روی staging)

1. **بکاپ کامل** فایل‌ها + دیتابیس، و یک بار **آزمودن بازگردانی** آن. خروجی تنظیمات
   LiteSpeed و شناسهٔ صفحهٔ اصلی فعلی («تنظیمات ← خواندن») را یادداشت کنید.
2. هش ZIP را بسنجید: `sha256sum tecteb-homepage-0.1.0.zip` ⇒ `20fcc4e1…274405`.
3. «افزونه‌ها ← افزودن ← بارگذاری» ← ZIP ← نصب ← **فعال‌سازی**. (ووکامرس باید فعال
   باشد.) تا اینجا هیچ چیزی روی سایت دیده نمی‌شود: افزونه فقط روی صفحه‌ای کار می‌کند که
   shortcode یا قالبش را دارد.
4. «ووکامرس ← صفحهٔ اصلی»: دسته‌ها را جست‌وجو، اضافه و مرتب کنید؛ نشانی‌ها را فقط اگر
   مقصد تأییدشده دارند بنویسید (برای staging می‌توانید در `wp-config.php`
   `define( 'TECTEB_HOME_SUPPLIER_URL', '/…/' );` بگذارید). جدول بالای صفحه می‌گوید
   کدام بخش دیده می‌شود و چرا.
5. در «محصولات» ستارهٔ «ویژه» را برای محصولات منتخب بزنید.
6. یک **صفحهٔ تازه** بسازید (صفحهٔ فعلی دست نخورد): Elementor Full Width + Hide Title +
   ویجت Shortcode `[tecteb_home]` — یا قالب «تک‌طب — تمام‌عرض» با همان متن. **پیش‌نویس
   یا خصوصی** نگهش دارید و با «پیش‌نمایش» ببینید.
7. اگر LiteSpeed ادغام/تأخیر CSS یا lazyload دارد: صفحهٔ پیش‌نمایش را بررسی کنید؛ در
   صورت لزوم `tecteb-home.css` و تصویر Hero (`hero-3d-dark`) را از آن بهینه‌سازی‌ها
   استثنا کنید.
8. متا و عنوان Rank Math ِ صفحهٔ اصلی فعلی را روی صفحهٔ تازه هم بنویسید.
9. آزمون‌های بند ۹ گزارش آمادگی؛ بعد **«تنظیمات ← خواندن ← صفحهٔ اصلی = صفحهٔ تازه»**
   و پاک‌کردن کل کش LiteSpeed.
