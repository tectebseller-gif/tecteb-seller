## تغییرها
1. **هدر از اولین رسم در حالت JS است (علت اصلی CLS ِ موبایل).** تا 0.2.4 ویژگی `data-js` را `header.js` (با
   `defer`) می‌گذاشت، یعنی **پس از** اولین رسم. در موبایل هدر یک لحظه در حالت بی JS (ردیف منو + جست‌وجوی باز،
   ~۳۲۱px) رسم می‌شد و بعد به ۶۷px جمع می‌شد و کل `main#content` ۲۵۴ پیکسل بالا می‌پرید — همان عنصری که PageSpeed
   مقصر CLS نام برده. حالا یک اسکریپت درون‌خطیِ کوچک، اولین فرزند `#tth-root`، همان ویژگی را پیش از رسم می‌گذارد.
   - فقط وقتی کار می‌کند که `header.js` واقعاً در صفحه و قابل اجرا باشد. اگر بهینه‌سازی (WP Rocket «Delay
     JavaScript execution»، LiteSpeed، …) `header.js` را تأخیری کرده باشد، کنار می‌کشد و رفتار همان 0.2.4 است.
   - اگر `header.js` بارگذاری نشود، پس از رویداد `load` ویژگی را برمی‌دارد و هدر به حالت کامل بی JS برمی‌گردد
     (پیوندهای ساده، ردیف منو)؛ هیچ دکمهٔ بی‌کاری نمی‌ماند. `header.js` با `data-tth-ready` خبر می‌دهد که اجرا شد.
   - ویژگی‌های `data-no-optimize="1" data-cfasync="false" nowprocket` تا بهینه‌سازها آن را جابه‌جا یا تأخیری نکنند.
2. **لوگو WebP ِ بی‌اتلاف** (۶٬۳۷۴ بایت به‌جای PNG ِ ۹٬۸۷۵ بایتی؛ همهٔ پیکسل‌های RGBA یکسان) و
   `fetchpriority="high"` فقط روی لوگوی نوار — همان عنصری که PageSpeed موبایل LCP نام برده
   (`img.tth-logo__mark`). نسخهٔ کشو بی‌تغییر. PNG در بسته می‌ماند.
3. **`tecteb-header.css` درون‌خطی** (۶۲۶ بایت) به‌جای یک فایل جدا — یک درخواست مسدودکنندهٔ رندر کمتر؛ همان
   قاعده‌ها، همان ترتیب cascade.
4. **`header.css` بی توضیح** (۳۳٬۸۶۴ ← ۲۷٬۷۲۸ بایت؛ gzip ۷٫۷ ← ۵٫۳ کیلوبایت) — همان قاعده‌ها، خروجی
   `tools/harden-css.py` (`--check` قبول).

**برابری ظاهر سنجیده شد:** `getComputedStyle` ِ ۷۲۰ عنصر × ۶۰ ویژگی و جعبهٔ هر عنصر در ۱۲ حالت (۳۲۰ تا ۱۹۲۰،
نوار چسبان دسکتاپ و موبایل، کشوی باز): **۰ تفاوت**؛ ۱۵ تصویر قبل/بعد: تنها تفاوت‌ها پیکسل‌های لوگو (حداکثر ۱ از ۲۵۵)
و دایرهٔ پیکان کارت‌های موبایل صفحهٔ اصلی که حالا دقیقاً روی جعبهٔ خودش رسم می‌شود (در 0.2.4 به‌خاطر همان پرش
۲٫۷px بالاتر رسم می‌شد). جزئیات: `../perf/evidence/visual/VERDICT.txt`.

## نصب و ارتقا (پس از تأیید شما، اول روی Staging)
1. پیشخوان ← افزونه‌ها ← افزودن ← بارگذاری ← `tecteb-header-0.2.5.zip` ← «جایگزینی نسخهٔ فعلی با نسخهٔ بارگذاری‌شده».
2. تنظیمات حفظ می‌شوند (آزموده: بایت‌به‌بایت). CSS با `?ver=0.2.5` بارگذاری می‌شود؛ پس از نصب، کش **صفحه‌ها**
   را در WP Rocket پاک کنید تا HTML ِ تازه (اسکریپت درون‌خطی و لوگوی WebP) سرو شود. تنظیمات WP Rocket را عوض نکنید.
3. بررسی در موبایل: بارگذاری صفحهٔ اصلی بی پرش هدر؛ کشو، جست‌وجو و دسته‌ها مثل قبل.
