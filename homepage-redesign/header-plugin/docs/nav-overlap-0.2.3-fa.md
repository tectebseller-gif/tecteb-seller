## ۱. علت — تأییدشده در کد و با بازتولید روی خودِ ZIP ِ 0.2.1

ردیف منوی دسکتاپ سه بخش دارد: دکمهٔ «دسته‌بندی کالاها»، فهرست پیوندهای «منوی اصلی»، و «همکاری تأمین‌کنندگان».
در 0.2.1:

```css
.tth-menu   { display: flex; …; min-inline-size: 0; }   /* فهرست اجازه دارد کوچک‌تر از متنش شود */
.tth-menu a { …; white-space: nowrap; }                  /* هر پیوند یک‌خطی است */
```

هیچ قاعده‌ای برای «جا نمی‌شود» نبود. پس وقتی پیوندهای منو از فاصلهٔ میان دو دکمه پهن‌ترند، جعبهٔ فهرست کوچک
می‌شود ولی متن پیوندها از آن بیرون می‌ریزد و پیوند(های) آخر **زیر «همکاری تأمین‌کنندگان»** می‌افتند — دقیقاً تصویر
شما.

اندازه‌گیری‌شده روی 0.2.1 نصب‌شده از ZIP، با همان هشت پیوندی که در تصویر سایت اصلی دیده می‌شود
(`tests/nav-overflow.mjs`، `evidence/nav-overflow/before-0.2.1.txt`):

| | پهنای لازم پیوندها | جای موجود | نتیجه |
|---|---|---|---|
| ۸ پیوند، ۱۷۶۰px (مثل تصویر شما) | **۹۱۹px** | **۷۶۳px** | «در تک طب فروشنده شوید» روی «همکاری تأمین‌کنندگان» |
| ۸ پیوند، ۱۰۸۰px | ۸۹۸px | ۶۰۳px | «تماس با ما» هم روی دکمه؛ پیوند آخر بیرون از ردیف |
| ۶ پیوند (منوی محلی/Staging)، ≥ ۱۱۸۰px | ≤ ۶۳۶px | ≥ ۶۲۷px | جا می‌شود — بی هم‌پوشانی |

جای موجود از ۷۶۳px بیشتر نمی‌شود چون عرض هدر سقف ۱۲۴۰px دارد؛ پس با هشت پیوند در **هیچ** عرضی جا نمی‌شود.
تصویر بازتولید: `evidence/nav-overflow/before-0.2.1-8-1760.png` (همان هم‌پوشانی تصویر شما).

**چرا روی Staging درست بود (استنتاج، نه بررسی Staging):** در تنظیمات محلی این افزونه — که از روی همان پیکربندی
ساخته شده — دو پیوند منو در «پنهان در هدر» هستند: **«دسته بندی کالا ها»** و **«در تک طب فروشنده شوید!»** (تکرار دو
دکمهٔ خودِ هدر). با آن دو، شش پیوند می‌ماند که جا می‌شود. روی سایت اصلی تنظیمات تازه است، هیچ پیوندی پنهان نیست و
هر هشت نمایش داده می‌شود.

## ۲. قالب، Elementor و CSS سراسری — علت نیستند
- هم‌پوشانی روی سایت محلی **بی هیچ CSS ِ دیگری** رخ می‌دهد؛ برای ساختنش فقط تعداد پیوندها لازم است.
- با CSS ِ بدخواه سراسری (قواعد واقعی Kit و frontend ِ Elementor 4.2.3 و الگوهای رایج Custom CSS) همان جواب، و
  آزمون ایزولگی **۰ تفاوت** در ۹ حالت (۶۶ عنصر × ۴۴ ویژگی) می‌دهد — CSS ِ قالب روی ردیف منو اثر ندارد.
- ⛔ CSS ِ واقعیِ سایت اصلی دیده نشده است. اگر پس از 0.2.3 هنوز چیزی روی هم بیفتد، علت دیگری است و این‌ها از
  مرورگر لازم است (فقط خواندن، DevTools ← Elements، روی یک پیوند منو و روی «همکاری تأمین‌کنندگان»):
  1. تب **Computed** ِ `.tth-menu a`: `font-family`، `font-size`، `letter-spacing`، `padding`، `white-space`؛
  2. تب **Styles** همان عنصر: نام فایل هر قاعده‌ای که از بیرون این افزونه (`header.css`) آمده؛
  3. پهنای `.tth-menu` و `.tth-nav__row` (روی جعبه در Elements)، و عرض پنجره؛
  4. تصویر همان بخش.

## ۳. اصلاح — یک قاعده، بی پنهان‌کردن هیچ عنصری
`homepage-redesign/header/shared/header-base.css` (CSS ِ نمونهٔ تأییدشده) ⇒ `tools/harden-css.py` ⇒
`tecteb-header/assets/css/header.css`:

```css
.tth-menu {
  display: flex;
  flex-wrap: wrap;                          /* تازه */
  align-items: center;
  gap: 0 clamp(0.25rem, 1.2vw, 1rem);       /* بود: gap: clamp(…) — فاصلهٔ سطرها ۰ */
  min-inline-size: 0;
}
```

پیوندی که جا نشود به **سطر دوم همان ستونِ منو** می‌رود — میان دو دکمه، هرگز روی آن‌ها. هیچ `display:none`، هیچ
پنهان‌کردن، هیچ کوچک‌کردن متن، هیچ تغییر در دکمه‌ها یا چیدمان کلی؛ RTL همان است.

| | 0.2.1 | 0.2.3 |
|---|---|---|
| ۸ پیوند، ۱۰۸۰ تا ۱۹۲۰px | پیوند(های) آخر زیر «همکاری تأمین‌کنندگان» | **بی هم‌پوشانی**؛ هفت پیوند در سطر اول، «در تک طب فروشنده شوید» در سطر دوم (ردیف ۸۸px به‌جای ۴۶px) |
| ۶ پیوند، ≥ ۱۱۸۰px | یک سطر | **بی هیچ تغییری** — تصویرها در ۱۲۸۰ و ۱۷۶۰ بایت‌به‌بایت یکسان |
| ۶ پیوند، ۱۰۸۰px | «درباره تک طب» ۱۸px بیرون از جعبهٔ منو (هنوز نه روی دکمه) | دو سطر، بی بیرون‌زدگی |
| زیر ۱۰۸۰px (تبلت و موبایل) | ردیف منو کشو است | **بی تغییر** |

تصویرها: `evidence/nav-overflow/after-8-1760.png`، `after-8-1280.png`، `after-6-1760.png`.

**پیشنهاد برای ظاهر نهایی (تصمیم مالک، بی کد):** دو پیوند تکراری را در «Tecteb Header ← تنظیمات ← پنهان در هدر»
تیک بزنید — «دسته بندی کالا ها» (همان کار دکمهٔ «دسته‌بندی کالاها») و «در تک طب فروشنده شوید» (همان کار
«همکاری تأمین‌کنندگان») — تا شش پیوند در یک سطر بمانند، مثل Staging. پیوندها در «نمایش ← فهرست‌ها» دست نمی‌خورند.
⚠️ ذخیرهٔ تنظیمات این افزونه کل کش WP Rocket را پاک می‌کند؛ با جایگزینی خاموش بازدیدکننده تفاوتی نمی‌بیند.

## ۵. آزمون ایمن روی سایت اصلی (فقط پس از مجوز جداگانه)
1. پشتیبان. **کلید «جایگزینی هدر Elementor» خاموش بماند.**
2. افزونه‌ها ← افزودن ← بارگذاری `tecteb-header-0.2.3.zip` ⇒ «جایگزینی نسخهٔ فعلی». بارگذاری نسخه هیچ تنظیمی را
   ذخیره نمی‌کند؛ قالب‌های ۲۰ و ۲۶۵۲ تیک‌خورده می‌مانند.
3. در پنجرهٔ ناشناس صفحهٔ اصلی: همان هدر قدیمی (بازدیدکننده تفاوتی نمی‌بیند).
4. با مدیر `https://tecteb.com/?tth_preview=1` در عرض‌های مختلف (یا DevTools ← حالت دستگاه، ۱۰۸۰ تا ۱۹۲۰): هیچ
   متنی روی «همکاری تأمین‌کنندگان» نباید باشد؛ با هشت پیوند، پیوند آخر در سطر دوم.
5. (اختیاری، تصمیم مالک) پنهان‌کردن دو پیوند تکراری (بند ۳) ⇒ یک سطر.
6. انتشار عمومی جدا و پس از تأیید: روشن‌کردن کلید جایگزینی.
