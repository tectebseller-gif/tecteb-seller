## تغییر
فقط برای دسکتاپ (≥۱۰۸۰px) و فقط پس از اسکرول (`.is-compact`):
- منوی همبرگری نمایش داده نمی‌شود — نه بالای صفحه و نه پس از اسکرول.
- نوار چسبان یک ردیف **۶۳ پیکسلی** است، به ترتیب RTL: لوگو › «دسته‌بندی کالاها» › جست‌وجو › «حساب من» و سبد.
- «دسته‌بندی کالاها» همان دکمه و همان Mega Menu ِ ردیف دوم است (همان DOM و JS)؛ با کلیک، Enter و Escape، زیر نوار.
- در **حالت عادی هدر** (بالای صفحه) «همکاری تأمین‌کنندگان» و پیوندهای منو سر جایشان‌اند؛ فقط در نوار چسبان پنهان‌اند.
- تبلت و موبایل (زیر ۱۰۸۰px): همبرگری و کشوی RTL بی‌تغییر.
- مرورگرِ بی `subgrid` (Chrome زیر ۱۱۷، Safari زیر ۱۶، Firefox زیر ۷۱): نوار چسبان دوردیفه، بی همبرگری.

منبع: `homepage-redesign/header/shared/header-base.css` (یک بلوک `@media (min-width: 1080px)`)؛
`assets/css/header.css` خروجی `tools/harden-css.py` از همان منبع است (`--check` قبول).

## نصب و ارتقا (پس از تأیید شما، اول روی Staging)
1. پیشخوان ← افزونه‌ها ← افزودن ← بارگذاری ← `tecteb-header-0.2.4.zip` ← «جایگزینی نسخهٔ فعلی با نسخهٔ بارگذاری‌شده».
2. تنظیمات حفظ می‌شوند (آزموده: بایت‌به‌بایت). HTML ِ هدر عوض نمی‌شود؛ CSS با `?ver=0.2.4` بارگذاری می‌شود، پس
   مرورگر و کش صفحه فایل تازه را می‌گیرند. اگر WP Rocket/LiteSpeed CSS را ترکیب یا کوچک می‌کند، یک بار پاک‌سازی
   کش **همان صفحه‌ها** کافی است (نه پاک‌سازی کل سایت).
3. بررسی: در دسکتاپ اسکرول کنید — یک ردیف، بی همبرگری؛ «دسته‌بندی کالاها» Mega Menu را باز می‌کند.

## بازگشت به 0.2.3
- **فوری، بی نصب:** مدیر با `?tth_original=1` هدر قدیمی Elementor را می‌بیند (آزموده روی 0.2.4).
- **بازگشت نسخه:** همان مسیر بارگذاری با `tecteb-header-0.2.3.zip` (SHA-256 ِ بالا) و «جایگزینی». تنظیمات
  دست‌نخورده می‌مانند و HTML همان است (آزموده در `upgrade-023.sh`).
- **خاموش‌کردن کامل هدر مستقل:** «مدیریت هدر ← جایگزینی هدر» ← خاموش؛ هدر Elementor برمی‌گردد.
