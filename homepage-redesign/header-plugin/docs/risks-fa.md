## اطلاعاتی که برای جایگزینی ایمن ۲۶۵۲ هنوز لازم است
1. **فهرست محتوای قالب ۲۶۵۲** (ریسک ۲) — مهم‌ترین مورد.
2. وضعیت «Cache for logged-in users» و «Remove Unused CSS» در WP Rocket.
3. آیا قالب هدر Theme Builder ِ دیگری (حتی پیش‌نویس با شرط) وجود دارد؟ — جدول افزونه روی Staging همین را فقط‌خواندنی نشان می‌دهد.
4. نام افزونهٔ علاقه‌مندی (اگر نماد آن لازم است) و صفحهٔ آن.
5. قالب فعال سایت (Hello Elementor؟): مسیر `elementor_theme_do_location('header')` در هر دو حالت (قالب سازگار یا «overwrite» ِ Elementor Pro) همان است، ولی دانستنش آزمون را کامل می‌کند.
