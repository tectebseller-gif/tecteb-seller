## راه‌حل
وصلهٔ قبلی (۶۳ ← ۱۱۰px) کنار گذاشته شد. حالا فقط برای دسکتاپ (≥۱۰۸۰px) و فقط پس از اسکرول (`.is-compact`):
- همبرگری نمایش داده نمی‌شود — نه بالای صفحه و نه پس از اسکرول.
- نوار یک ردیف است، به ترتیب RTL: **لوگو › «دسته‌بندی کالاها» › جست‌وجو › «حساب من» و سبد**.
- دکمهٔ «دسته‌بندی کالاها» و Mega Menu همان عنصرهای ردیف دوم‌اند؛ DOM، قالب PHP و JavaScript تغییر نکرده‌اند.
  نوار یک CSS grid می‌شود و ردیف بالا و ردیف منو هر دو `subgrid` ِ همان ردیف‌اند، پس دکمه فقط ستون دوم را می‌گیرد.
- پیوندهای منو و «همکاری تأمین‌کنندگان» فقط در نوار چسبان پنهان‌اند؛ بالای صفحه سر جایشان‌اند.
- مرورگری که `subgrid` ندارد (Chrome زیر ۱۱۷، Safari زیر ۱۶، Firefox زیر ۷۱) همان دو ردیف را می‌بیند، بی همبرگری.
- زیر ۱۰۸۰px (تبلت و موبایل) هیچ قاعده‌ای تغییر نکرد: همبرگری و کشوی RTL همان‌اند.

- هنگام ساخت 0.2.4: شمارهٔ نسخه در `tecteb-header.php` و `readme.txt`.
