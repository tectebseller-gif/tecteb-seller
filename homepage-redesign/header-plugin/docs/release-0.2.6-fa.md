## تغییر
وقتی Header B هدر Elementor را جایگزین می‌کند، Elementor Pro تا 0.2.5 همچنان CSS ِ آن قالب (`post-<ID>.css` یا همان CSS
درون‌خطی)، فونت‌ها و کتابخانه‌های آیکونش (مثل Font Awesome) و «دارایی‌های صفحه» ِ ابزارک‌هایش (`widget-nav-menu`،
`widget-search`، `widget-icon-box`، `widget-social-icons`، `widget-image`، `e-animation-buzz-out`، `e-apple-webkit`،
`smartmenus`) را در `<head>` می‌گذاشت — چون تصمیم چاپ‌نکردن بعداً گرفته می‌شود. هیچ‌کدام چیزی را روی صفحه نمی‌آراست.

0.2.6 درست پیش از گام بارگذاری Pro (`wp_enqueue_scripts` اولویت ۹) با فیلتر عمومی خودِ Pro قالب‌های جایگزین‌شده را
از آن گام پنهان می‌کند و درست پس از آن (اولویت ۱۱) برمی‌گرداند؛ پس رندر و جایگزینی دقیقاً همان 0.2.5 است. فقط وقتی که
جایگزینی واقعاً انجام خواهد شد (همهٔ اسناد هدر این صفحه در فهرست قالب‌های انتخاب‌شده؛ نه در پیش‌نمایش/ویرایشگر،
`?tth_original=1`، صفحهٔ خودِ قالب یا وقتی جایگزینی خاموش است). اگر در لحظهٔ رندر Elementor هدر خودش را چاپ کند،
همان دارایی‌ها دوباره بارگذاری می‌شوند. دارایی‌هایی که فوتر، Popup یا خودِ صفحه لازم دارند دست نمی‌خورند.

**روی بستر Elementor ِ واقعی** (فقط هدر): CSS ِ `<head>` در یک برگهٔ معمولی ۲۴ ← ۱۶ (۸ فایل: `post-2652.css` و ۷ CSS ِ
ابزارک)، به‌اضافهٔ `smartmenus.js`؛ در صفحهٔ نخست به‌همراه Homepage 0.3.7 ۳۱ ← ۱۶. در سه حالت Elementor (فایل CSS، «Internal Embedding»، آیکون فونتی) `<head>` پس از جایگزینی **دقیقاً**
همان است که Elementor اگر قالب هدر اصلاً منتشر نشده بود بارگذاری می‌کرد (`../perf/tests/elementor-modes.sh`).

## نصب و بازگشت
نصب: افزونه‌ها ← افزودن ← بارگذاری ← `tecteb-header-0.2.6.zip` ← «جایگزینی نسخهٔ فعلی»؛ سپس پاک‌کردن کش WP Rocket (و
Used CSS اگر RUCSS روشن است). بازگشت: همان مسیر با `tecteb-header-0.2.5.zip`؛ هیچ کار دیتابیسی لازم نیست. مقایسهٔ فوری
بی نصب: مدیر با `?tth_original=1` هدر Elementor را با همهٔ دارایی‌هایش می‌بیند.

**ریسک باقی‌مانده:** Custom CSS ای که در **خودِ قالب هدر Elementor** برای عنصری **بیرون از هدر** نوشته شده باشد دیگر
بارگذاری نمی‌شود (همان CSS ِ همان سند است). روی بستر نبود؛ روی Production تأییدنشده — پس از نصب روی Staging هر عنصری
بیرون از هدر را که سبکش عوض شده گزارش کنید.
