# چک‌لیست دقیق تست Staging و بازگشت — tecteb-header 0.2.0

> فقط **پس از مجوز جداگانهٔ مالک** و فقط روی `staging.tecteb.com`. هیچ گامی از این فهرست تا امروز
> اجرا نشده است. سایت اصلی خارج از این چک‌لیست است.

محیط اعلام‌شده: Elementor 4.2.3 · Elementor Pro 4.2.2 · JetMenu 3.0.4 · WooCommerce 11.0.1 ·
WP Rocket 3.23.2.2 (Minify CSS روشن؛ Combine، Defer/Delay JS و Lazyload خاموش) · قالب هدر
«Header» ۲۶۵۲، منتشرشده، شرط «کل سایت» · فهرست «منوی اصلی» با ۱۳ پیوند سفارشی JetMenu.

## ۰. پیش از هر کار (بی تغییر در سایت)
- [ ] پشتیبان کامل Staging (فایل‌ها + پایگاه داده) و یادداشت زمان آن.
- [ ] **خروجی قالب ۲۶۵۲** («Elementor ← قالب‌ها ← خروجی گرفتن» یا فهرست ابزارک‌ها): چه چیزهایی
      جز لوگو/جست‌وجو/حساب/سبد/علاقه‌مندی/منو در آن است؟ (مثلاً نوار اعلان، کد رهگیری، دکمهٔ تماس،
      ابزارک Popup، اسکریپت سفارشی، Schema). هر چه آنجاست پس از جایگزینی **دیگر چاپ نمی‌شود** (بخش ۴).
- [ ] تنظیمات WP Rocket: «کش برای کاربران واردشده» (Cache for logged-in users) و «Remove Unused CSS»
      روشن است یا خاموش؟
- [ ] نام و نسخهٔ افزونهٔ علاقه‌مندی، نشانی صفحهٔ آن؛ نام افزونهٔ «جستجو سریع» (اگر لازم است).
- [ ] تطبیق SHA-256 ِ ZIP با `dist/SHA256SUMS`.

## ۱. نصب (نباید هیچ چیز دیداری عوض شود)
- [ ] نصب و فعال‌سازی `tecteb-header-0.2.0.zip`.
- [ ] چند صفحه را به‌عنوان مهمان ببینید: **همان هدر ۲۶۵۲** (جایگزینی پیش‌فرض خاموش است و هیچ چیزی ذخیره نشده).
- [ ] پیشخوان: «تک‌طب ← مدیریت هدر» (اگر منوی «تک‌طب» از قبل هست، زیر همان؛ منوی تکراری نه).
- [ ] `wp-content/debug.log` (اگر WP_DEBUG_LOG روشن است): هیچ خطای «tecteb-header».

## ۲. دسته‌ها (فقط از product_cat)
- [ ] «انتقال از منوی فعلی» ← فهرست «منوی اصلی» ← «خواندن». هر پیوند سفارشی با **نشانی‌اش** به دستهٔ
      واقعی نگاشته می‌شود؛ انتظار: ۱۳ ردیف «قطعی» یا «فقط هم‌نام». ردیف‌های «فقط هم‌نام» را با مسیر
      دسته بسنجید و فقط در صورت درستی تیک بزنید. ردیفی که به هیچ دسته‌ای نمی‌رسد را با جست‌وجوی
      زبانهٔ «دسته‌بندی‌ها» دستی انتخاب کنید.
- [ ] تیک «جایگزینی فهرست» ← ذخیره. «دادهٔ ذخیره‌شده»: ۱۳ شناسه، به همان ترتیب، فقط شناسه.
- [ ] «پنهان‌کردن دستهٔ بی‌محصول» خاموش بماند.
- [ ] آیکون هر دسته از کتابخانهٔ رسانه (PNG/WebP؛ اگر دسته در ووکامرس تصویر PNG/WebP دارد، دکمهٔ
      «تصویر دسته در ووکامرس»). زیردسته‌های منتخب از فهرست تیک‌دار (فقط زیرمجموعه‌ها؛ حداکثر ۱۲).
- [ ] تأیید در ووکامرس: هیچ دسته‌ای ساخته، ویرایش یا حذف نشده (تعداد دسته‌ها و تاریخ‌ها همان).

## ۳. تنظیمات
- [ ] منوی اصلی: «منوی اصلی»؛ پنهان: «دسته بندی کالا ها» و «در تک طب فروشنده شوید!» (اگر سطح اول‌اند).
- [ ] پیوند همکاری `/landing-seller/`؛ علاقه‌مندی: «نمایش داده نشود» یا «پیوند» به صفحهٔ واقعی.
- [ ] «به‌روزرسانی شمارندهٔ سبد با cart fragments» روشن بماند (بخش ۶).

## ۴. انتخاب قالب و پیش‌نمایش فقط برای مدیر
- [ ] زبانهٔ «جایگزینی هدر»: جدول باید **Header #2652 — منتشرشده — شامل: کل سایت** را نشان دهد (فقط خواندن).
      اگر قالب هدر دیگری با شرط هست، یادداشت کنید (دست نمی‌خورد و در صفحه‌های خودش همان می‌ماند).
- [ ] فقط ۲۶۵۲ را تیک بزنید؛ کلید جایگزینی **خاموش** بماند؛ ذخیره.
      ⚠️ ذخیره در این صفحه کل کش WP Rocket را پاک می‌کند (`rocket_clean_domain`)؛ اگر نمی‌خواهید، پیش از
      ذخیره هماهنگ کنید.
- [ ] با مدیر: `?tth_preview=1` روی صفحهٔ اصلی، فروشگاه، یک دسته، یک محصول، سبد، تسویه، حساب من،
      نتیجهٔ جست‌وجو، وبلاگ و یک نوشته، درخواست تعمیرات، `/landing-seller/`، ۴۰۴، صفحه‌های Dokan/بازارگاه.
      در هر کدام: **فقط یک هدر**؛ فوتر Elementor سر جایش؛ نبود سرریز افقی؛ منبع صفحه توضیح
      `<!-- tecteb-header: replaced Elementor header template 2652 -->` دارد.
      اگر توضیح «not replaced: …» دیدید: `not_allowed` (قالب دیگری برای آن صفحه)، `no_manager` یا
      `queue_not_emptied` (رفتار Elementor Pro با کد خوانده‌شده نمی‌خواند — **روشن نکنید**؛ گزارش دهید).
- [ ] اندازه‌ها: ۱۴۴۰، ۱۰۲۴، ۷۶۸، ۳۹۰، ۳۲۰؛ Mega Menu دوستونه (۱۳ دسته، زیردسته‌ها، پیوند به صفحهٔ
      دسته)، کشوی موبایل با همان دسته‌ها و منو، دکمهٔ جست‌وجوی موبایلِ صفحهٔ اصلی، حالت چسبان.
- [ ] جست‌وجو (نتیجه‌های محصول)، ورود/ثبت‌نام، منوی حساب (کاربر واردشده)، خروج.
- [ ] پنجرهٔ ناشناس (مهمان): `?tth_preview=1` **نباید** اثری داشته باشد.
- [ ] `?tth_original=1` (مدیر) همان ۲۶۵۲.

## ۵. روشن‌کردن جایگزینی روی Staging
- [ ] کلید جایگزینی ← روشن ← ذخیره (کش WP Rocket پاک می‌شود). در پنجرهٔ ناشناس همهٔ صفحه‌های بخش ۴.
- [ ] Minify CSS ِ WP Rocket: ظاهر هدر همان پیش‌نمایش (در محیط محلی با همان کتابخانهٔ کوچک‌سازی
      یکسان بود)؛ فونت Vazirmatn بارگذاری شود (DevTools ← Network ← font).
- [ ] اگر «Remove Unused CSS» روشن است: Mega Menu، کشو و منوی حساب را **باز** کنید؛ اگر بی‌سبک‌اند،
      `tecteb-header` را از RUCSS مستثنا کنید.
- [ ] Lighthouse/PageSpeed صفحهٔ اصلی و یک محصول، قبل و بعد (CLS، LCP).

## ۶. سبد و کش
- [ ] مهمان: افزودن کالا ← رفتن به صفحهٔ دیگری که از کش WP Rocket می‌آید ← شمارندهٔ سبد درست (cart fragments).
- [ ] مهمانِ بی‌سبد: در یک نشست فقط یک درخواست `wc-ajax=get_refreshed_fragments` (DevTools).
- [ ] کاربر واردشده: نام خودش در منوی حساب؛ اگر «کش برای کاربران واردشده» روشن است، با دو کاربر
      متفاوت بسنجید که نام دیگری دیده نشود.
