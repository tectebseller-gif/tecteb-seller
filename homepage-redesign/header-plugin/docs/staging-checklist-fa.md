# چک‌لیست اتصال آینده روی Staging

> این چک‌لیست برای **بعد از تأیید جداگانهٔ مالک** است. تا آن زمان هیچ گامی اجرا نمی‌شود.
> همه‌چیز فقط روی `staging.tecteb.com`، نه سایت اصلی.

## پیش از نصب — اطلاعاتی که لازم است
- [ ] نسخهٔ Elementor و Elementor Pro، و قالب فعال (Hello Elementor؟ نسخه؟).
- [ ] نام و نسخهٔ افزونهٔ **علاقه‌مندی‌ها** (و نشانی صفحهٔ آن).
- [ ] نام افزونهٔ **جست‌وجوی** «جستجو سریع …» و shortcode ِ آن (اگر دارد).
- [ ] تنظیمات LiteSpeed: Cache Logged-in Users، ESI، UCSS، CSS/JS Combine، Delay JS، Guest Mode.
- [ ] آیا «دسته بندی کالا ها» در ۲۶۵۲ از یک فهرست وردپرس است یا JetEngine/JetMenu؟ نام فهرست.
- [ ] پشتیبان کامل Staging (فایل و پایگاه داده) و یادداشت شرط نمایش فعلی ۲۶۵۲ («کل سایت»؟ استثناها؟).

## نصب (هیچ تغییر دیداری)
- [ ] بارگذاری `tecteb-header-0.1.0.zip` و تطبیق SHA-256 با `dist/SHA256SUMS`.
- [ ] فعال‌سازی. سایت باید **دقیقاً همان** بماند (جایگزینی خاموش است) — چند صفحه را ببینید.
- [ ] «تک‌طب ← مدیریت هدر» در پیشخوان؛ اگر منوی «تک‌طب» از قبل بود، زیر همان و بدون منوی تکراری.

## تنظیم
- [ ] «انتقال از منوی فعلی»: روش الف (فهرست وردپرس) یا ب (نام‌ها)؛ ۱۳ دسته با **شناسهٔ واقعی**.
      هر ردیف «پیدا نشد» یا «مبهم» را با جست‌وجوی زبانهٔ «دسته‌بندی‌ها» دستی انتخاب کنید.
- [ ] ترتیب ۱۳ دسته = ترتیب هدر فعلی. «پنهان‌کردن دستهٔ بی‌محصول» **خاموش** بماند.
- [ ] آیکون‌ها از کتابخانهٔ رسانه، فقط PNG یا WebP. زیردسته‌های منتخب برای هر دسته.
- [ ] «تنظیمات»: فهرست وردپرس منوی اصلی؛ پنهان‌کردن «دسته بندی کالا ها» و «در تک طب فروشنده شوید!».
      پیوند همکاری `/landing-seller/`. علاقه‌مندی: «نمایش داده نشود» یا «پیوند» به صفحهٔ واقعی.

## پیش‌نمایش (فقط مدیر، بی اثر روی بازدیدکننده)
- [ ] `?tth_preview=1` روی: صفحهٔ اصلی، فروشگاه، یک دسته، یک محصول، سبد، تسویه، حساب من، جست‌وجو،
      وبلاگ، درخواست تعمیرات، `/landing-seller/`، صفحه‌های Dokan/بازارگاه (پنل فروشنده).
- [ ] در هر کدام: **فقط یک هدر**، فوتر Elementor سر جایش، نبود سرریز افقی؛ دسکتاپ ۱۴۴۰ و ۱۰۲۴،
      تبلت ۷۶۸، موبایل ۳۹۰ و ۳۲۰.
- [ ] Mega Menu: ۱۳ دسته، زیردسته‌ها، پیوندها به صفحهٔ دستهٔ واقعی؛ کشوی موبایل همان دسته‌ها.
- [ ] جست‌وجو، ورود/ثبت‌نام، منوی حساب (کاربر واردشده)، سبد پس از افزودن کالا (شمارنده).
- [ ] با یک پنجرهٔ ناشناس (مهمان): `?tth_preview=1` **نباید** اثری داشته باشد.
- [ ] اگر `?tth_preview=1` هدر را عوض نکرد: Elementor Pro اکشن‌های Theme Builder را نمی‌زند ⇒
      جایگزینی روشن نشود؛ راه ب (Shortcode) یا گزارش برای بررسی.

## روشن‌کردن جایگزینی روی Staging
- [ ] زبانهٔ «جایگزینی هدر» ← روشن ← ذخیره ← Purge All در LiteSpeed.
- [ ] تکرار بررسی‌های پیش‌نمایش برای مهمان و کاربر واردشده؛ PageSpeed/Lighthouse قبل و بعد.
- [ ] `?tth_original=1` (مدیر) هنوز ۲۶۵۲ را نشان دهد.

## تمرین بازگشت
- [ ] خاموش‌کردن جایگزینی ← ذخیره ← Purge All ⇒ ۲۶۵۲ در همهٔ صفحه‌ها (مهمان).
- [ ] غیرفعال‌سازی افزونه ⇒ ۲۶۵۲؛ فعال‌سازی دوباره ⇒ تنظیمات سر جایش.
- [ ] تأیید اینکه ۲۶۵۲ و شرط نمایش آن هیچ تغییری نکرده‌اند (تاریخ ویرایش قالب در Elementor).

## گزارش به مالک
- [ ] نتیجهٔ هر بند، تصویرها، و هر ناسازگاری با LiteSpeed/Elementor/JetEngine. سایت اصلی **فقط** با
      تأیید جداگانه.
