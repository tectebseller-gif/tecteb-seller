# چک‌لیست نصب، تست Staging و بازگشت — tecteb-header 0.2.1

> فقط **پس از مجوز جداگانهٔ مالک** و فقط روی `staging.tecteb.com`. هیچ گامی از این فهرست تا امروز
> اجرا نشده است. سایت اصلی خارج از این چک‌لیست است.

محیط اعلام‌شده: Elementor 4.2.3 · Elementor Pro 4.2.2 · JetMenu 3.0.4 · WooCommerce 11.0.1 ·
WP Rocket 3.23.2.2 (Minify CSS روشن؛ Combine، Defer/Delay JS و Lazyload خاموش) · قالب هدر
«Header» ۲۶۵۲، منتشرشده، شرط «کل سایت» · فهرست «منوی اصلی» با ۱۳ پیوند سفارشی JetMenu.

- [ ] تطبیق SHA-256 ِ `tecteb-header-0.2.1.zip` با `dist/SHA256SUMS`.
- [ ] اگر 0.2.0 روی Staging نصب است: کلید «جایگزینی» خاموش باشد پیش از به‌روزرسانی (0.2.0 در یک حالت
      نادر دو هدر چاپ می‌کرد؛ 0.2.1 اصلاحش کرده).

## ۱. نصب، بی فعال‌سازی، و بررسی فقط‌خواندنی ۲۶۵۲

## ۳. دسته‌ها (فقط از product_cat) و تنظیمات

## ۴. انتخاب قالب و پیش‌نمایش فقط برای مدیر
- [ ] زبانهٔ «جایگزینی هدر»: جدول **Header #2652 — منتشرشده — شامل: کل سایت** (فقط خواندن). قالب هدر
      دیگری با شرط را یادداشت کنید (دست نمی‌خورد).
- [ ] فقط ۲۶۵۲ را تیک بزنید؛ کلید جایگزینی **خاموش** بماند؛ ذخیره.
- [ ] با مدیر، `?tth_preview=1` روی: صفحهٔ اصلی، فروشگاه، یک دسته، یک محصول، سبد، تسویه، حساب من،
      نتیجهٔ جست‌وجو، وبلاگ و یک نوشته، درخواست تعمیرات، `/landing-seller/`، ۴۰۴، صفحه‌های Dokan/بازارگاه.
      در هر کدام: **فقط یک هدر**؛ فوتر سر جایش؛ نبود سرریز افقی؛ منبع صفحه:
      `<!-- tecteb-header: replaced Elementor header template 2652 -->`.
- [ ] اگر توضیح «not replaced: …» دیدید — **روشن نکنید**، گزارش دهید:
      `not_allowed` (قالب دیگری) · `no_manager` · `queue_not_emptied` · `elementor_printed_before`
      (مکان header پیش‌تر در همین درخواست چاپ شده) · `elementor_printed` (کسی دوباره سند Elementor را
      به صف افزود و Elementor آن را چاپ کرد؛ 0.2.1 در این حالت هدر خودش را چاپ نمی‌کند).
- [ ] **ظاهر در برابر CSS ِ سایت:** هدر باید با پیش‌نمایش محلی یکی باشد — رنگ پیوندها، دکمه‌ها،
      کادر جست‌وجو، فهرست‌ها (بی نقطه یا تورفتگی)، اندازهٔ لوگو و آیکون‌ها. هر تفاوتی را با DevTools
      (Elements ← Computed ← منبع قاعده) یادداشت کنید: قاعدهٔ `!important`، قاعدهٔ با ID، یا `html{font-size}`
      (`risks-fa.md` ردیف ۱۷).
- [ ] **جای خالی بالای صفحه:** اگر بین هدر و محتوا فاصلهٔ اضافه یا هم‌پوشانی هست، احتمالاً قاعدهٔ سراسری
      `post-2652.css` (مثل `body{padding-top}`) است — بند ۱ را ببینید.
- [ ] اندازه‌ها ۱۴۴۰، ۱۰۲۴، ۷۶۸، ۳۹۰، ۳۲۰؛ Mega Menu، کشوی موبایل، جست‌وجوی موبایل صفحهٔ اصلی، حالت چسبان.
- [ ] جست‌وجو، ورود/ثبت‌نام، منوی حساب، خروج.
- [ ] پنجرهٔ ناشناس (مهمان): `?tth_preview=1` **بی اثر**؛ مدیر: `?tth_original=1` همان ۲۶۵۲.
